Everything you need to call an API. Nothing you don’t.

Bikasend is a stripped-down alternative to Postman and Bruno for teams whose services already document themselves.

Open a folder, get every endpoint

Point it at any repo. It finds every Swagger and OpenAPI file, JSON or YAML, lists the operations by tag, and reloads when a spec changes.

Example bodies, filled in

Request bodies come pre-filled from the schema, with examples, enums and defaults, so you change values instead of typing JSON.

Swagger 2.0 and OpenAPI 3

Reads the files swag generates, plus OpenAPI 3.0 and 3.1, with $ref across files. Path, query and header parameters and auth headers are set up for you.

Secrets stay in memory

API keys and tokens never touch disk or logs. They only go to the hosts your environment lists or a host you confirm, never over plain http without asking, and never along a redirect to another host or to plain http.

No CORS, no proxies

Requests run natively, not from a browser, so local, staging and internal services just work.

Small and fast

About 10 MB, starts instantly and uses your system’s own web view. It works offline, with no account and no telemetry.

Variables and environments

Write {{"{{baseUrl}}"}} or {{"{{api_key}}"}} anywhere. A bikasend.json in the repo shares environments such as local and staging with the whole team.

AWS secrets, loaded on demand

Reference AWS Secrets Manager or Parameter Store. Bikasend loads the values into memory with your own aws CLI login. The repo only ever holds where a secret lives.

Responses checked against the spec

See a JSON tree, search, timing and images, plus every place the response breaks its schema. Copy any request as cURL, with secrets left out.

From repo to response in three steps

No collection to build first. Your Swagger files already describe every request.

  1. 1

    Open your repo

    Pick a folder. Bikasend finds its Swagger and OpenAPI files and remembers the folder for next time.

    ~/code/example-repo3 specs
  2. 2

    Pick an operation

    Filter by path, method or summary. The URL, headers and body come filled in, and an environment such as staging fills the variables.

    GET/items/{id}
  3. 3

    Send

    Press ⌘ Enter or Ctrl Enter. See the status, time, size, headers and pretty-printed JSON.

    200 OK42 ms · 116 B

Install and verify

macOS blocks the app the first time

Builds are not notarised by Apple yet. Unzip and move Bikasend.app to Applications, then open it once and close the warning. Go to System Settings → Privacy & Security, scroll down and click Open Anyway. On macOS 14 and earlier you can right-click the app and choose Open instead. After that it opens normally.

Windows SmartScreen shows a warning

The executable is not code-signed yet. Choose More info → Run anyway. If the window stays blank, install the Microsoft Edge WebView2 runtime. It comes with Windows 11.

Linux: missing library errors

Install GTK and WebKitGTK: sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0 on Debian and Ubuntu, or sudo dnf install gtk3 webkit2gtk4.1 on Fedora.

How do I verify a download?

Compare the SHA-256 shown next to each download with your file. On macOS and Linux run shasum -a 256 <file>. On Windows run Get-FileHash <file> in PowerShell. Don’t run the file if they don’t match.

Which Swagger files does it read?

Bikasend reads JSON and YAML files whose name contains swagger or openapi, plus the folder’s bikasend.json once you trust it. It skips .git, node_modules and vendor, and never reads a file outside the folder.

Where do my secrets go?

Nowhere but the request. Values you type, values Bikasend asks for, and values it loads from AWS stay in the app’s memory and are gone when you quit. A shared bikasend.json holds only references such as an AWS secret name, and Bikasend refuses to save a secret-looking value in it.
